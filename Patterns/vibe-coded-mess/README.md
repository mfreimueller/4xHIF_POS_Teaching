# European Singing Championship 2026 Vienna – Official Scoring API

---

## About This Project

This is the **official backend** for the European Singing Championship 2026 in Vienna (definitely not related to the ESC).
The visionary product owner decided to cut costs and use a LLM (large language model) instead of human engineers to produce the code.

Given that the product owner promised fast delivery, they prompted the LLM to produce fast and without complexity (i.e., not to worry about cumbersome things such as extensibility or good coding practices in general).

The code you see in this repository is the result of this vibe coded... experience.

It is your job to analyze the code in this repository and introduce proper patterns (the way we discussed them in class).

Essentially, there are four patterns that are relevant to you:
- builder pattern
- repository pattern
- façade pattern
- strategy pattern

... if you encounter more patterns that would make sense, feel free to introduce them.

### Hints

1. Throughout the project, the AI wrote comments 'explaining' its decisions. Those are your guiding-beacons.
2. Focus on the controller classes.
3. If you feel bored, feel free to refactor the models as well (ValueObjects, RichTypes, etc.)
